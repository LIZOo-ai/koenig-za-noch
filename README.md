# КЁНИГ ЗА НОЧЬ 🏙️

**Угадаешь, сколько стоит ночь в этом городе?**

Интерактивная игра-викторина о стоимости посуточного жилья в Калининграде. Ты рассматриваешь фотографии реальных квартир, называешь свою цену за ночь — и узнаёшь, насколько попал в реальный рынок.

- **50 реальных объявлений** Avito (посуточная аренда квартир в Калининграде)
- **10 раундов** за игру — квартиры отбираются стратифицированно по ценовым сегментам
- **1000 баллов** максимум — точность каждого ответа превращается в баллы
- **Персональный профиль** в конце: Охотник за выгодой, Ценовой навигатор или Любитель комфорта

> Цены в игре — реальные объявления с условиями: **одна ночь, два гостя, 14–15 ноября 2026 года**. На другие даты стоимость может отличаться.

## Как играть

1. Смотри фотографии квартиры и её характеристики.
2. Выбери цену одной ночи бегунком или введи точное значение.
3. Зафиксируй ответ — узнай реальную цену, отклонение и баллы.
4. После 10 раундов получи персональный профиль и статистику.

Баллы за раунд: `max(0, 100 × (1 − |оценка − цена| / цена))`.

## Структура проекта

```
koenig-game/
├── index.html          # разметка всех экранов
├── css/
│   └── styles.css      # фирменный стиль, адаптив, анимации
├── js/
│   ├── game.js         # игровая логика: отбор квартир, баллы, профили, статистика
│   └── ui.js           # компоненты интерфейса: галерея, бегунок, экраны
├── data/
│   ├── listings.js     # данные объявлений (подключается как window.LISTINGS)
│   └── listings.json   # те же данные в JSON
└── tools/
    └── parse_csv.ps1   # генератор data/ из исходного CSV
```

Исходный CSV кладётся рядом и обрабатывается скриптом:

```powershell
powershell -File tools/parse_csv.ps1 -CsvPath "путь\к\файлу.csv" -OutDir data
```

## Запуск

Проект статический — никаких сборки и зависимостей. Достаточно открыть `index.html` в браузере, а для публикации — любой статический хостинг (например, GitHub Pages).

## Технические детали

- Mobile-first, без горизонтальной прокрутки, свайп-галерея, large touch-targets.
- Фотографии подгружаются лениво; при ошибке загрузки показывается заглушка.
- Состояние игры сохраняется в `sessionStorage` — перезагрузка страницы не сбрасывает прогресс.
- Игровая логика отделена от UI (`js/game.js` / `js/ui.js`).
- Ссылки на оригинальные объявления открываются в новой вкладке и ведут именно на ту квартиру, что показана в раунде.
